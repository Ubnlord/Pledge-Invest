# Supabase migration smoke tests

Run these after configuring Supabase Auth providers and Edge Function secrets.

## Public API
- GET /api/_healthcheck returns { "message": "Success" }.
- GET /api/public/market returns market data or a clear upstream error.
- GET /api/public/deposit-settings returns the current public settings.

## Authentication
- Unauthenticated GET /api/me/summary returns 401.
- A valid Supabase-authenticated investor can load /api/me/summary and /api/profile.
- A non-admin authenticated user gets 403 from /api/admin/overview.
- The allowlisted admin must pass both Supabase authentication and the server-side PLEDGE_ADMIN_AUTH_CODE check.

## Ledger
- Investor account and transactions are stored in Supabase public.pledge_records through the Edge Function.
- Deposit requests do not credit a balance until admin approval.
- Test deposit approval, wallet credit, withdrawals, referral rewards, and profit accrual only with test accounts.
- Verify that account and shared investor records stay in sync.

## Known migration requirement
Existing AppDeploy data has not been imported. Do not use financial controls against real balances until the legacy records have been exported/imported and reconciled.
